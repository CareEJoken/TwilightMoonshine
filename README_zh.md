# 暮色月光 (Twilight Moonshine)

*English README: [README.md](README.md)*

**暮色月光** 是一个基于 [NeoForge](https://neoforged.net/) 的暮色森林附属模组。在暮色湖泊群系与月兔相遇、调制药水，看森林里的小虫子在月光下开演唱会。

需要 **Minecraft 1.21.1**、**NeoForge 21.1.x** 与 **暮色森林 4.8+**。

## 功能

### 月兔与月光
- **月兔** —— 暮色湖泊群系周围的兔子小伙伴；喂食胡萝卜（或金胡萝卜）会让它不断变大。
- **月光私酿** —— 饮用后获得 8 分钟的防火、水下呼吸与夜视。把三种独特的药水交给月兔即可换取一瓶。
- **月石** —— 新石材系列：月石碎片、月石块、月石砖、楼梯、台阶、墙与碎片堆。
- *月之铃与"满月终临"进度 —— 开发中，本版本暂未包含。*

### 酿造与炼金
- 新增药水效果：**抗性**、**微微发亮**、**发光**与**暮色**，均有普通/长时、喷溅与滞留形态，及药箭、光谱之箭配方。
- **秘密配方** —— 通过神秘书页发掘暮色植物萃取液、暮色荧光精华与暮色合金粉末的隐藏配方。
- **暮色合金粉末** 与 **神秘书页** —— 探索发现秘密配方并合成。

### 暮色森林调整（服务端数据包 + mixin）
- 重新启用 **蘑菇塔** 与 **任务岛** 世界结构，并附带自定义地图装饰。
- 暮色光照：自定义暮色暗度曲线与暮色维度调色光图。
- 新增进度：*跺跺脚！*、*拥抱日*、**夕阳甲虫乐队**、*光之川*、*暮色岗哨守卫*、*手手相传* 与 *柯立芝家族*。

### 夕阳甲虫乐队（三重奏演出）
把粘液甲虫、喷火甲虫和巨钳甲虫聚集在唱片机旁并播放唱片：三只甲虫会面朝唱片机、跟着节拍蹦跳，并轮流演奏一段 **三声部轮唱**（低音 + 铃铛 + 拨弦），每只虫还会冒出自己颜色的音符。

## 依赖

| 依赖 | 版本 |
|------|------|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.x |
| 暮色森林 (Twilight Forest) | 4.8+ |

**必须安装暮色森林**（本模组不包含/不打包暮色森林的任何文件）；客户端、专用服务器均可使用。

## 安装

1. 为 Minecraft 1.21.1 安装 **NeoForge 21.1.x**（推荐 21.1.191+）。
2. 在同为 `mods` 目录下安装 **暮色森林** 1.21.1 版本。
3. 将 `twilightmoonshine-1.0.0.jar` 与 `twilightforest-*universal.jar` 一起放入 `mods`。
4. 启动游戏，可在 **暮色月光** 创造标签下（月兔战利品、药水、月之铃等）看到本模组物品。
